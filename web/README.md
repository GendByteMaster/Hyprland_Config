# Hyprland_Config web page

React + TypeScript landing page for the Hyprland_Config project.

## Development

```bash
cd web
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated static site is written to `web/dist/`.

## Vercel

Use `web` as the project root directory. Vercel will detect Vite automatically:

- Build command: `npm run build`
- Output directory: `dist`
